# 決戰 2026 預測積分賽

2026 九合一縣市長選舉預測積分賽網頁。參賽者在網頁上作答，送出的預測會存進主辦方的 Google 試算表。

## 設定收件（Google 試算表）

1. 新建一份 Google 試算表，名稱自訂。
2. 選單「擴充功能 > Apps Script」，刪掉預設內容，貼上 `apps-script/Code.gs` 的全部內容，存檔。
3. 右上角「部署 > 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，依指示授權，複製產生的網址（結尾是 `/exec`）。
5. 打開 `index.html`，把 `PASTE_APPS_SCRIPT_URL_HERE` 換成剛剛的網址。

第一份預測送出後，試算表會自動建立「預測名單」工作表與標題列。

## 規則設定

- 截止時間：2026/11/27 23:59（台灣時間）。`index.html` 與 `Code.gs` 各有一個 `DEADLINE`，要改時兩邊一起改。
- 同一個暱稱只能送出一次；同一台裝置送出後會顯示已封存的結果。
